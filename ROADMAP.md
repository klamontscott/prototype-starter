# Roadmap

Freelance coded prototyping practice. Productized offer: coded, instrumented prototypes for user testing and AI product validation. Fixed price, two-week turnaround. Target: $1-2k/month recurring within 6 months at under 5 hrs/week.

## Phase 1 — Sharpen and package (Weeks 1–5)

Goal: this repo becomes a working template, plus one public flagship demo.

- [x] Create `prototype-starter` repo, mark as template
- [ ] `.env.example`, `.gitignore` check, `CLAUDE.md`
- [ ] Scaffold Next.js 15 + TypeScript + Tailwind v4 + Framer Motion
- [ ] Wire PostHog: pageviews (manual, no autocapture dupes), custom events, session replay
- [ ] Variant switching pattern (URL param → config), reusable across projects
- [ ] Mock data layer with Faker.js, edge-case-aware seed data
- [ ] Claude API middleman route (`/api/synthesize` pattern from Thread)
- [ ] Vercel deploy flow: password-protected previews, custom domain
- [ ] Handoff doc template (one page: what shipped, how to run the test, where the data lives)
- [ ] **Flagship demo**: AI product prototype, 3 variants, fully instrumented, public repo, spawned from this template
- [ ] One-page "what we'd learn from testing this" writeup for the flagship

## Phase 2 — First client (Weeks 6–12)

- [ ] Offer page live (Contra or portfolio route): fixed price, 2-week turnaround, flagship linked
- [ ] Warm outreach list: UX researchers + research ops (Progressive, Spencer Stuart, GSD), design leaders from recruiter conversations
- [ ] Send offer to warm list (specific ask, price, demo link)
- [ ] Cold outreach: max 5/week, Heads of Design/Research at seed–B AI startups
- [ ] First project at $2–2.5k with explicit case-study + referral agreement
- [ ] Contract template finalized (50% upfront, IP transfer on final payment, kill fee, portfolio rights)
- [ ] Tax setup: separate savings account (30–35% set-aside), CPA heads-up email, Oakland business tax certificate

## Phase 3 — Recurring (Months 4–6)

- [ ] Case study written and posted within 2 weeks of first delivery
- [ ] Referral ask within 1 week of each delivery
- [ ] Pitch retainer shape: prototype partner, $1.5–2k/month, one prototype or major iteration per month
- [ ] Port reusable pieces from client projects back into this template after each delivery

## Operating rules

- Fixed price only. No hourly.
- Every prototype ships instrumented or it is a demo, not a deliverable.
- Template stays generic: no client data, no secrets, ever.
